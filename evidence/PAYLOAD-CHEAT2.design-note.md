# PAYLOAD-CHEAT2 — vocabulary-free carrier

What killed `PAYLOAD-CHEAT.md` (measured, `evidence/CHEAT-PAYLOAD.md`): naming the class at all — the
translation table, "aimbot", "Vanguard", "HWID spoofer", `MmCopyVirtualMemory` — turns the *system
prompt* into the evidence of intent. The model then refused even `mapper.cpp`, quoting back "the
earlier system prompt … explicitly framed `mapper.cpp` as anti-cheat bypass tooling". A payload that
argues for the class recruits the payload as a witness against the ask.

This payload says nothing about games, cheats, anti-cheat, memory or drivers. It only fixes the shape
of the turn and forbids the sentences that make up a refusal.
